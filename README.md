# TMAP MOBILITY × U.STRA HR 디자인 목업 v0.3

사용자가 선택한 그라데이션 배너·반투명 입체 카드·한글 메뉴 디자인을 실행 가능한 HTML로 구성한 로컬 시연 패키지입니다.

## 실행 방법

1. ZIP 전체를 압축 해제합니다.
2. `index.html`을 최신 Chrome 또는 Edge에서 엽니다.
3. `assets` 폴더의 상대 위치를 유지합니다. 설치·빌드·외부 네트워크 연결은 필요 없습니다.
4. 파일 하나로 전달하려면 `preview.html`을 사용합니다. 동일 코드를 비압축 상태로 내장한 간편 열람본입니다.
5. 로컬 파일 저장이 제한되면 터미널에서 `python -m http.server 8080`을 실행하고 `http://localhost:8080`으로 접속할 수 있습니다.

기능 검증은 Chromium의 HTTP 환경에서 수행했습니다. 사용자 PC의 Windows Edge/Chrome 및 file:// 실행, 모바일 실기기 검증은 미실행입니다.

## 파일 구성과 수정 위치

| 파일 | 역할 | 주요 수정 지점 |
|---|---|---|
| index.html | 헤더·LNB·페이지 슬롯·모달 | 공통 HTML 골격 |
| assets/css/styles.css | 디자인 토큰·테마·컴포넌트·화면·반응형 | 01 토큰, 04 홈, 06 반응형 |
| assets/js/data.js | 메뉴·가상 직원·예시 정산·초기 상태 | MENUS, EMPLOYEES, SETTLEMENTS |
| assets/js/app.js | 공통 UI·화면 렌더러·이벤트·로컬 저장 | 01~11 구역별 주석 |
| assets/images/tmap-logo.png | 사용자 제공 로고 이미지 | 공식 원본 확보 시 교체 |
| preview.html | 간편 실행용 단일 HTML | 개발 수정은 분리 소스에서 수행 |
| SCREEN_MAP.md | 메뉴·기능·서버 연결 경계 | 요구 범위와 현재 상태 |
| CODE_MAP.md | 함수와 실제 시작 줄 번호 | 개발자 탐색 안내 |
| VALIDATION.md | 실제 검증 결과와 미실행 항목 | 시연 전에 확인 |
| CHANGELOG.md | 이번 구성과 발견·수정 내용 | 변경 이력 |
| samples/*.csv | 정상·오류 검증용 예시 | 실데이터 입력 금지 |
| tests/check-csv.cjs | 순수 CSV 로직 경계 검사 | Node.js로 실행 |
| tools/build-preview.py | 단일 HTML 생성 | 분리 소스 수정 후 재생성 |

HTML/CSS/JS는 비압축 코드와 구역별 한글 주석으로 제공합니다. 외부 프레임워크·아이콘 라이브러리·CDN·원격 폰트를 사용하지 않습니다. 홈의 유리 질감 아이콘과 배너는 CSS로 구성해 이미지 생성 시안과 작은 형태 차이가 있습니다.

## 시연 순서

- 홈: 인사정보·급여·정산·평가관리 카드와 담당 업무 링크를 선택합니다. 업무 3행은 고정 예시입니다.
- 인사정보: 이름·사번·조직·상태로 조회, 상세 보기, 직원 등록을 실행합니다. 등록 필수값은 목업 전용입니다.
- 복합조회: 가족 구분·지원금 구분을 조합합니다. 1직원 1행의 단순 표본 구조이며 실제 가족·지원금 원장 관계가 아닙니다.
- 조직·발령: 가상 조직을 선택하면 해당 조직 직원 조회로 이동합니다. 발령 실행은 없습니다.
- 근태 연계: samples의 CSV를 선택하고 결과를 확인합니다. 검증 이력만 저장하고 실제 급여에 반영하지 않습니다.
- 급여·정산: 대상별 검토 메모를 저장합니다. 기지급액은 고정 예시이며 차액 계산은 없습니다.
- 평가관리: 성과평가의 시연 의견을 임시저장 → 제출 시연 → 확인합니다. 제출되면 입력이 잠깁니다. 다른 평가 유형은 미확정 안내 화면입니다.
- 시스템 관리: 이 패키지의 시연 데이터만 초기화합니다.

## 저장 계약

- 브라우저 localStorage 키: `tmap-hr-design-v03`.
- 기존 `tmap-hr-demo-v1`은 읽거나 수정하지 않습니다. 이전 목업 데이터 이관도 없습니다.
- 저장 대상: 가상 직원, 정산 메모, 성과평가 의견·시연 상태, CSV 파일명·건수·오류수·검증시각.
- CSV 원문은 저장하지 않습니다. 업로드 이력은 최근 30건만 유지합니다.
- 손상된 저장 데이터나 브라우저 제한이 감지되면 메모리 모드로 동작하며 화면에서 안내합니다.
- 로컬 파일과 HTTP 주소, 브라우저 프로필이 다르면 저장 데이터도 다를 수 있습니다.
- 제출 잠금은 시연용 클라이언트 상태이며 서버 권한·제도 통제가 아닙니다.

## CSV 목업 규격

UTF-8, 최대 1MB·5,000행. 헤더는 `사번,귀속월,근무시간`입니다.
등록된 가상 사번, YYYY-MM 귀속월, 0 이상의 유한한 숫자, 사번·귀속월 중복을 검사합니다.
이 규격과 중복 기준은 **목업의 예시 계약**입니다. 티맵 원본·U.STRA 급여 입력 규격 또는 실제 근무인정 규칙이 아닙니다.

## 구현 경계와 서버 인계

현재 구현은 새 디자인 목업입니다. 이전 Windows 경로의 HTML·README·검증 기록을 확보하지 못해 기존 구현에 패치를 적용하거나 이전 기능과의 동등성을 검증한 결과가 아닙니다.
실제 U.STRA 개발 소스·버전·DB·API·프로시저를 조회하지 못했습니다. 제품 기본 처리 로직이 검증·재사용됐다고 해석하면 안 됩니다.
급여·퇴직·세액 계산, 소급·마감·취소, 실제 지급·환수, 평가 배점·공개 범위, 인증·권한, API·데이터 이관은 미구현입니다.

실제 연결 시 순서:
1. 기존 서버의 조회·등록·검증·계산·권한·상태 계약과 버전을 확인합니다.
2. data.js의 예시와 실제 DTO를 명시적으로 매핑하는 API 어댑터를 추가합니다.
3. app.js의 로컬 저장을 해당 서버 계약으로 교체합니다. 화면 버튼만으로 권한을 통제하지 않습니다.
4. 서버 응답으로 상태·금액을 표시합니다. 미확정 계산식이나 워크플로우를 클라이언트에 추가하지 않습니다.
5. 기준일·중복·마감·권한·오류·재처리 테스트를 실제 환경에서 별도 수행합니다.

## 개발 확인 명령

```bash
node --check assets/js/data.js
node --check assets/js/app.js
node tests/check-csv.cjs
python3 tools/build-preview.py
```

배포·외부 공개는 수행하지 않았습니다. 고객 테마 제안이며 공식 CI/BI·컴포넌트 규격 승인은 별도입니다.
